# 影视与 AI 漫剧

这里汇总视频类作品：AI 漫剧、游戏影像与剪辑。

## AI 漫剧

生产管线已开源：[ai-manju](https://github.com/Brambleaaaaaa/ai-manju)

```text
角色资产 → 场景资产 → 道具资产 → 分镜草图 → 分镜 CG → Seedance 合成 → 补帧/修复
```

- 26 个 ComfyUI 工作流，覆盖角色四视图、八/九表情、场景多机位、白模深度控图、道具、分镜、成片。
- 角色一致性靠参考图编辑 LoRA + 四视图 LoRA；镜头一致性靠深度/姿态 Control。
- 成片环节使用 Seedance 2.5（付费接口）。

样帧与补帧测试片段见 [ai-manju/samples](https://github.com/Brambleaaaaaa/ai-manju/tree/main/samples)。
