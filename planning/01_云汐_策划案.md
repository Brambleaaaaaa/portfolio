## 一、基础功能与按键需求（Input Mapping System）

|功能定义|物理按键 \(PC\)|逻辑事件 \(Event Name\)|触发模式 / 行为规则|

### 2\. 局内暂停与设置系统（Pause Menu \& Settings）

**全局时钟控制：**按下 ESC 弹出暂停小面板时，程序触发 Time\.timeScale = 0（游戏全局逻辑暂停），同时将 UI 输入映射切换为 UI Navigation 模式；关闭面板时恢复 Time\.timeScale = 1。

|界面层级|控件名称|控件类型|交互逻辑与功能描述|
|---|---|---|---|
|暂停主面板 \(Pause Panel\)|继续游戏 \(Resume\)|Button|恢复游戏时钟 \(timeScale = 1\)，隐藏暂停面板|
||游戏设置 \(Settings\)|Button|隐藏当前暂停面板，压入（Push）并渲染“设置面板”|
||返回主界面 \(Main Menu\)|Button|探出提示窗口即是否存档。若是则回到主界面，若否则返回局内界面。\(Scene\_MainMenu\)|
|设置界面 \(Settings Panel\)|配音音量 \(Voice Volume\)|Slider / Button|调节语音/配音 AudioMixer 参数，区间 0\.0 \~ 1\.0|
||音乐音量 \(BGM Volume\)|Slider / Button|调节背景音乐 AudioMixer 参数，区间 0\.0 \~ 1\.0|
||屏幕大小 \(Resolution\)|Dropdown / Button|切换窗口模式/分辨率（如 Fullscreen, 1920x1080, 1280x720）|



### 3\. 局内 HUD 与动态反馈 UI（In\-Game HUD）
