# 官方世界观设定 v1

> 状态：草案 ｜ 2026-10-15
> 用途：官方剧本默认使用的世界；写手招募后第一个要发给对方的东西。
> 关联：[官方剧本创作规范.md](官方剧本创作规范.md) ｜ [规则系统规格-v1.md](规则系统规格-v1.md)
> 游戏代号（暂定）：**《记史人》**

---

## 一、一句话定位

**在一个刚学会用电的旧大陆上，有一群靠记录怪事吃饭的人。他们的工作不是消灭异常，而是把它写清楚——代价是他们会因此受伤、变老、被记住，最后被写进自己的最后一页。**

---

## 二、为什么是这个世界（设计意图）

这个设定的每一个元素都在为系统服务，不是随便挑的时代背景：

| 系统机制 | 在世界观里的位置 |
|---|---|
| 角色跨剧本长期养成、会老 | 记史是**一辈子的行当**，一个记史人可以干四十年 |
| 伤势跨剧本携带 | 记录异常的代价**是身体**，伤口不会因为案子结了就好 |
| 美德需要被目击 | 行当圈子小，**名声传得比人快**；有人看见才算数 |
| 编年史 / 悼词 | 记史人的工作成果**本身就是文字**，一生就是一份档案 |
| 世界线分叉 | 同一件事可以被记录成不同的版本，**记录有分歧** |
| 撕卡 | 档案的最后一页写的是他怎么死的 |
| 认知类特质给额外信息 | 见过世面的人**看得见别人看不见的东西** |

**一句话：把机制变成世界观，而不是给机制贴一层皮。**

---

## 三、世界

### 时代

**蒸汽与电气交替的百年**（质感约当 1860–1960，但不映射真实历史的任何一个具体年份）。城市里有煤气灯也有电灯，有马车也有刚铺好的铁道，报纸和电报同时存在。

**为什么不给具体年份**：写手不用背历史，玩家不会因为考据出戏，我们也不会碰到真实历史的争议。

### 地理

架空大陆 **「环海诸邦」**。不需要完整地图，先立四座据点城市，每座支撑一类剧本：

| 城市 | 质感 | 适合写什么 |
|---|---|---|
| **灰港** | 常年下雨的港城，码头、货栈、三教九流 | 都市悬疑、走私、失踪案 |
| **钟岭** | 山城，旧贵族与钟表匠聚居，雾大 | 密室、家族秘辛、精密诡计 |
| **铁砧** | 工业城，工厂、工会、烟囱与污水 | 劳工冲突、机器事故、群体性事件 |
| **旧都** | 半废弃的旧首都，图书馆、档案馆、空荡的宫殿 | 文献调查、历史真相、政治阴影（架空） |

### 异常

**克制、不解释。** 世界里确实有解释不了的事，但**没有任何人知道它们从哪来**，也没有统一的理论。有人叫它「留白」，有人叫它「不该有的东西」。

**给写手的铁律：不要给异常设定统一的起源、等级体系或幕后黑手。** 一旦解释了，恐惧就没了，而且会锁死后面所有写手的手脚。每一桩案子可以有自己的规则，但**没有人在世界观层面知道全局**。

### 异常是真的吗？（作者层答案，玩家永远拿不到确证）

**是真的。** 但这句话只有我们和写手知道——**玩家在本子里永远无法证明它**。

| 层 | 谁知道 | 内容 |
|---|---|---|
| **世界观层** | 我们与写手 | 异常存在，但没有规律、没有来源、没有幕后，无人知道全局 |
| **剧本层** | 写手必须写清 | 每个本子有一个**确定的真相**，并注明属于哪一类（真实异常／人为伪装／不可判定） |
| **玩家层** | 玩家 | 永远无法确证世界观层的事实，只能逼近剧本层的真相 |

**为什么必须「存在」——三条硬理由：**

1. **认知类特质需要它。** 如果一切都能还原为人为，那「神秘学」就是废技能，玩家不会为它去冒险——这会直接打掉我们最核心的机制（认知类特质必须给额外可见信息）。
2. **「记史」这个行当需要它。** 记史人的职责是记录，不是解决。如果什么都能破案，他们就变成侦探了，世界观当场塌掉。
3. **紧张感需要它。** 玩家一旦总结出规律（「都是人干的」或「都是鬼干的」），第三种本子就再也吓不到人。**不确定本身就是产品。**

三类真相要**分布着用**，不要连着两个都用「人为伪装」——玩家会总结出规律，然后你所有的恐怖描写都失效。

### 记史人

他们不属于任何官方机构。**「校验所」**是行当里最接近组织的东西——一个松散的民间网络：有人提供线索，有人出钱，有人核对记录，但**没有人下令**。

- 记史人接活可以收钱，也可以因为「这件事得有人写下来」而不收钱。
- 他们没有执法权。遇到事，多数时候只能**记录、求证、然后决定要不要动手**。
- 行当里有派系：有人认为该把一切都写下来，有人认为有些东西就该烂在纸外。

### 行话（写手可直接用）

| 词 | 含义 |
|---|---|
| **记史** | 到现场、搞清楚、写下来 |
| **校验** | 交叉验证，确认记录没有撒谎 |
| **留白** | 解释不了的部分。行话里不带恐惧色彩，只表示「这里空着」 |
| **封存** | 决定不公开、不追查、把记录锁起来 |
| **分线** | 同一件事，出现两种互相矛盾的记录 |
| **同期** | 一起办过案子的人。这个词比「朋友」更重 |

## 四、写手要记住的四条

1. **玩家是记录者，不是英雄。** 剧本要给他们「搞清楚一件事」的满足感，而不是「打败一个反派」。
2. **代价必须落到身上。** 每次正确的调查都可能让人受伤、让人失去什么、让人再也回不去。这是我们的核心体验。
3. **没有全知视角。** NPC 不掌握真相，写手也不要在剧本里安排一个「其实我早就知道一切」的角色。
4. **架空但不轻浮。** 不要写真实国家、真实宗教、真实人物、现实政治事件。可以参考真实时代的质感，但所有专有名词必须是原创的。

---

## 五、给写手的默认锚

写手如果不知道从哪下手，就用这个组合：

> **灰港，某个下雨的晚上，一桩看起来很小的事。**

或者从这四类里挑一个：**失踪** / **不该动的旧东西** / **有人说了不该说的话** / **一笔收不到的钱**。

## 六、可写题材清单（对应剧本类型）

| 题材 | 说明 | 判定侧重 |
|---|---|---|
| 都市失踪 | 一个人消失了，所有人都说他还在 | 调查、街头门路、说服 |
| 旧物异常 | 从土里／当铺／遗产里出来的一件东西 | 神秘学、机械、语言 |
| 家族秘辛 | 旧贵族的宅子里有不能说的事 | 感知、说服、共情 |
| 工业事故 | 不是事故 | 机械、医术、运动 |
| 文献调查 | 一份档案自相矛盾 | 语言、智识、调查 |
| 群体事件 | 一整个街区的人同时做了什么 | 风度、共情、意志 |
| 同期之死 | 曾经一起办案的人死了 | 意志（重）、调查 |

**每个剧本至少要让玩家在「记录」与「动手」之间做一次真实的选择**——而这两个选择应当都有代价。

---

## 七、红线（不可写）

1. 真实国家、真实民族、真实宗教、真实历史事件、真实在世人物。
2. 已有作品的角色、地名、组织、专有名词——**包括我们自己不拥有的任何 IP**。
3. 现实政治立场、现实争议话题。
4. 给异常设定统一起源／等级／幕后黑手。
5. 涉及未成年人的性内容、详细的自伤方法、真实可复现的危险操作。

---

## 八、与招募信息的一处衔接

《剧本招募信息》里写的是「世界观必须原创」。补一条界定：

- **官方委托剧本默认使用本设定**（省掉写手自建世界的成本，也让官方剧本彼此呼应）。
- 写手如果提案**独立世界观**，也可以谈——但必须原创、自洽，且不能与官方设定冲突。

建议把这一条补进招募信息，避免写手误以为每写一个剧本都要自己造一个世界。
