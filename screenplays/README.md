## 写作约定

- 游戏剧本统一使用“角色代号 + 台词 / 旁白 / 画面效果 / 音频”的格式，方便程序直接解析。
- 章节切换、字幕节奏、演出时长会在剧本中直接标注。
- 跑团剧本按场景与分支组织，保留主持人提示。
