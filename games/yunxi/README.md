# 云汐

> 2D 平台跳跃与解谜 ｜ PC ｜ 策划中

一个以平台跳跃、解谜与探索叙事为核心的 2D 项目。策划案已完成 V0.1，包含输入映射、角色物理参数、战斗/技能、分裂与合并、洞明（探查）等系统设计。

## 核心设计

- **移动手感**：土狼时间 0.15s、输入缓冲 0.12s、蓄力高跳、长跳、跳闪、翻滚无敌帧。
- **分裂 / 合并**：角色可分裂为四个 mini 小蜘蛛，再合并回本体（G 键）。
- **洞明**：长按 1s 引导，消耗次数探查隐藏信息。
- **战斗**：普攻连段、两个技能槽、格挡、治疗；若团队配置不足则退回纯解谜探索。
