# Correct Error

> 反乌托邦 ｜ 剧情 ｜ 恐怖 ｜ TapTap 聚光灯 Game Jam ｜ 2025-10-29

**“自由即枷锁，知识即地狱。”**

玩家扮演卫生所的一名心理医生，负责寻找、治疗、清除“异常”的人类个体。今天来了一位奇怪的病人，她似乎怎样都无法回归正常，而你原本平静的生活也就此被打破。

- TapTap：[Correct Error](https://tap.cn/lrdmk1ZrY)（9.1 分 / 14 条评价）
- 开发：乌络游戏
- 标签：反乌托邦、剧情、恐怖、聚光灯 GameJam

## 设计要点

- 单场景对话推进，靠文本与演出来制造压迫感。
- 以“治疗异常”为表层玩法，逐步揭开世界观的裂缝。
- Game Jam 周期内完成从文案、美术到可玩循环的完整交付。
